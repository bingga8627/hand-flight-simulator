# AERONAUT — 웹캠 손동작 비행 시뮬레이터

HTML, CSS, JavaScript와 Canvas 2D로 만든 1인칭 비행 프로토타입입니다. MediaPipe Hand Landmarker로 최대 두 손을 추적합니다. npm 설치, 빌드, Three.js, 서버 API가 필요하지 않습니다.

## 파일

- `index.html`: 비행 화면, 웹캠 미리보기, 계기판, 상태 표시, 조작 안내
- `style.css`: 어두운 조종석 테마, 녹색 HUD, 반응형 화면
- `main.js`: 웹캠, 모델 초기화, 손 추적, 핀치, 조종 입력, 비행 상태, Canvas 렌더링

각 파일에는 실행에 필요한 전체 코드가 작성되어 있습니다.

## 실행 방법

### VS Code Live Server — 권장

1. VS Code에서 이 폴더를 엽니다.
2. **Live Server** 확장 프로그램을 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 선택합니다.
4. 열린 `http://127.0.0.1:5500` 또는 `http://localhost:5500` 페이지에서 **웹캠 연결**을 누릅니다.
5. 브라우저의 카메라 권한 요청을 허용합니다. 첫 실행은 모델 다운로드 시간이 필요합니다.

### Python이 설치되어 있다면

이 프로젝트 폴더에서 터미널을 열어 실행합니다.

```sh
python -m http.server 5500 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:5500>을 엽니다. 종료는 터미널에서 `Ctrl+C`입니다.

`index.html`을 파일로 직접 열기보다 로컬 서버를 사용하세요. 외부 기기에서 LAN IP의 HTTP 주소로 접속하면 카메라 사용이 제한될 수 있으며, 원격 배포 시 HTTPS가 필요합니다. 첫 버전은 데스크톱 Chrome 또는 Edge의 넓은 창에서 사용하도록 설계했습니다.

## 조작 방법

1. 카메라를 정면에 두고 손가락과 손목이 잘 보이도록 앉습니다. 밝은 환경과 단순한 배경이 좋습니다.
2. 미리보기의 랜드마크와 `LEFT / RIGHT` 라벨을 확인합니다. 실제 손과 라벨이 반대이면 **왼손 / 오른손 인식 교환**을 켭니다. 미리보기와 화면 커서는 거울 방향으로 움직입니다.
3. 기본 **이지 조종**에서는 한 손을 보여주면 자동으로 조종이 활성화됩니다. 핀치는 필요하지 않으며 처음 인식된 위치가 중립점입니다.
4. 손을 왼쪽/오른쪽으로 움직이면 좌/우 Roll, **위로 움직이면 Pitch Up, 아래로 움직이면 Pitch Down**입니다. 조종 방식 메뉴에서 기존 `고급 · 핀치/거리` 방식으로 전환할 수도 있습니다.
5. 이지 모드에서 손을 화면 밖으로 빼면 조종간을 놓고 자세가 부드럽게 중앙/수평으로 복귀합니다. 다시 손을 보여주면 그 위치에서 중립점이 새로 설정됩니다.
6. **왼손**은 핀치 여부와 관계없이 높이로 스로틀을 조절합니다. 웹캠 화면 높이의 위쪽 22% 지점은 100%, 아래쪽 82% 지점은 0%입니다. 그 밖은 0~100%로 제한합니다. 손을 화면 밖으로 빼면 마지막 값을 유지합니다.
7. **비행 초기화**는 현재 모드를 처음부터 다시 시작합니다. 자유 비행은 속도 120 KTS, 고도 2,400 FT, 스로틀 55%, 수평 자세로 복귀합니다. 훈련 모드는 시작 위치에서 일시정지합니다. 손 중심 설정은 유지하며, 손이 보이면 다음 추적 프레임부터 현재 손 위치의 입력이 다시 적용됩니다.
8. **웹캠 끄기**는 카메라 스트림을 종료합니다. 페이지를 나가면 스트림과 모델도 정리합니다.

손의 위치는 미리보기 전체를 비행 화면 전체로 대응시킵니다. 조종간을 잡기 위해 실제 손을 카메라 화면 중앙 아래로 내려야 하므로 손가락이 카메라 밖으로 잘리지 않도록 카메라 각도와 거리를 조절하세요. 한 손만 보여도 해당 손의 기능은 독립적으로 작동합니다.

## 활주로 이착륙 훈련

화면 위에서 **지상 출발** 또는 **착륙 연습**을 선택합니다. 훈련은 준비를 위해 일시정지 상태로 시작합니다. 웹캠·손 중심·출력을 준비한 뒤 **비행 시작**을 누르거나, 조종간을 잡고 5% 이상 움직이면 자동으로 시작합니다. `P` 키는 일시정지/재개, `B` 키는 지상 브레이크 전환입니다. 카메라를 끄거나 다른 탭으로 이동하면 훈련이 일시정지합니다. 중심 설정 중에도 비행 이동은 멈춥니다.

훈련 중에는 화면 중앙에 비행 유도 마름모가 나타납니다. 지상에서는 활주로 중심선, 이륙 후에는 목표 상승 자세, 착륙 연습에서는 활주로 방향과 3° 진입 경로를 안내합니다. 손으로 기수를 움직여 마름모를 중앙 자세 기준선에 겹치면 `유도: 정렬`로 바뀝니다.

착륙 연습은 진입 접근 → 안정 접근 → 최종 접근 → 플레어 → 접지 → 활주 단계로 이어집니다. HUD의 목표 속도와 레이더 고도(`RA`)를 확인하고 100/50/30/20/10 FT 음성 콜아웃을 따라갑니다. 60 FT 아래에서는 유도 마름모가 `FLARE`로 바뀌며 목표 Pitch +3~5°를 안내합니다. 120 FT 아래에서 Pitch가 -2°보다 높으면 착륙 보조가 하강률을 점차 완화합니다.

### 지상 출발

1. 활주로 위에서 속도 0, 고도 0으로 시작합니다. 왼손을 올려 스로틀을 80% 이상으로 맞춥니다.
2. 브레이크는 OFF여야 합니다. 오른손 좌우 입력으로 지상에서 활주로 중심을 유지합니다.
3. 70 KTS 이상이 되면 오른손을 조금 위로 올려 Pitch를 4° 이상 올립니다.
4. 공중에서는 좌우 입력이 Roll로 작동합니다. 고도 100 FT를 통과하면 이륙 성공 안내가 나옵니다.
5. 계속 선회해 돌아와 착륙할 수 있습니다. 빠르게 접근을 연습하려면 **착륙 연습**을 누릅니다.

### 착륙 연습

활주로 2.4km 앞, 고도 460 FT, 속도 100 KTS에서 시작합니다. 활주로는 길이 2,200m, 폭 60m이고 방위 300°/120° 양쪽에서 접근할 수 있습니다.

1. 스로틀 약 30~35%를 시작점으로 80~100 KTS를 유지하세요. 왼손을 화면 밖으로 빼면 출력을 유지할 수 있습니다.
2. 오른손을 중립보다 조금 아래로 내려 Pitch 약 -3°로 완만하게 내려갑니다. 이는 이 게임의 기본 접근 예시이며 실제 조종 지침이 아닙니다.
3. HUD의 **중심선 편차**, **진입 높이**, **활주로 거리**를 보면서 흰 접지 표식과 `TOUCHDOWN` 원을 향해 접근합니다. 진입 높이는 표식까지의 거리로 계산한 3° 경로 대비 차이입니다.
   - 활주로 옆 PAPI가 흰색 2개·빨간색 2개면 적정 3° 경로입니다. 흰색이 많으면 높고 빨간색이 많으면 낮습니다.
   - 점선 `EST. TOUCHDOWN` 표시는 현재 고도·하강률·속도를 유지했을 때의 예상 접지점입니다. `SHORT`, `LONG`, `OFF RUNWAY`가 보이면 경로를 수정하세요.
4. 지면 가까이에서 오른손을 조금 올려 하강률을 줄이고 날개를 수평으로 맞춥니다.
5. 안전하게 접지하면 스로틀이 자동으로 줄고 브레이크가 작동합니다. 오른손으로 활주로 중심선만 유지하세요.
6. 활주로 안에서 3 KTS 미만까지 감속하면 착륙 완료입니다. 점수와 접지 속도·하강률·기울기·중심선 편차를 표시합니다.

판정값은 게임용이며 `main.js`의 `RUNWAY` 상수에서 조정합니다. 유효 접지는 활주로 안쪽(양옆 3m 여유), 속도 45~130 KTS, 하강률 최대 720 FT/MIN, Roll 최대 12°, 활주로와의 방위 차이 최대 18°, Pitch -3~12°입니다. 활주로 밖 접지·과도한 하강·방향 이탈·활주로 밖으로 굴러 나감은 이유를 표시하고 훈련을 종료합니다. 결과창에서 같은 훈련을 재시도할 수 있습니다.

## 통합 미션

상단의 **통합 미션**을 누르면 산악 도시 순환, 군도 해상 순찰, 사막 저고도 침투, 야간 항법 비행 중 하나를 선택할 수 있습니다. 카드에는 난이도, 권장 속도와 브라우저에 저장된 최고 점수가 표시됩니다. 선택한 미션의 맵은 자동으로 적용되고 현재 날씨는 그대로 유지됩니다.

미션은 지상 출발부터 착륙까지 한 번에 진행합니다. 이륙 후 맵마다 다르게 배치된 노란 `GATE 1~5` 링을 순서대로 통과하세요. 각 링의 세로 평면을 지날 때 중심에서 좌우 155m, 지정 고도 ±180 FT 안이면 통과로 인정됩니다. 보이는 링은 작은 크기로 표시하지만 판정 범위는 넓게 유지했으며, 거리에 따른 원근 크기로 그려져 가까워질수록 화면 밖까지 커집니다. 통과 직전에는 안쪽 잔상이 벌어집니다. 링을 놓치면 주황색 `GATE MISSED` 효과와 실패 이유가 표시되고, 1번은 이륙 직후의 안전 위치로, 2번부터는 직전에 통과한 게이트 위치로 돌아가 현재 링을 다시 시도합니다. 통과 순간에는 화면 섬광과 확장 원, `GATE CLEAR` 문구가 나타납니다. 모든 링을 지나면 먼 거리를 회항하지 않고 활주로 1.6km 앞의 짧은 최종 접근 위치로 자동 전환됩니다. 최종 점수는 착륙 품질 75%와 비행 시간 25%를 합산하며 성공한 최고 점수를 미션별로 저장합니다.

**자유 비행** 버튼으로 기존 비행 모드로 돌아갈 수 있습니다. 모든 활주로와 표식은 Canvas 2D 다각형의 원근 투영으로 그리며 3D 엔진은 사용하지 않습니다.

## 사운드

Web Audio API로 저음 엔진 진동, 터빈 휘파람, 저역 흡기음과 고역 배기음을 별도 레이어로 합성합니다. 스로틀이 오르면 터빈 회전음과 바람 대역이 함께 열리고, 80% 이상에서는 배기 노이즈가 강해지는 애프터버너 구간이 적용됩니다. 엔진 버스의 다이내믹 컴프레서가 여러 레이어의 피크를 눌러 소리가 찢어지는 현상을 줄입니다. 게이트 성공은 상승음, 게이트 실패는 하강 경고음으로 구분됩니다. 착륙 중에는 브라우저 음성 합성으로 100/50/30/20/10 FT를 읽고, 위험한 하강률에는 `SINK RATE`를 반복 안내합니다. 활주로 정렬은 HUD와 유도 마름모로만 표시합니다. 음성 합성을 지원하지 않는 브라우저에서는 구분되는 경고음만 재생됩니다. 브라우저 자동 재생 정책에 따라 페이지에서 버튼을 처음 누른 뒤 소리가 시작됩니다. 상단의 **사운드 ON/OFF** 버튼으로 언제든 끌 수 있으며 외부 음원 파일은 사용하지 않습니다.

70 KTS 전에는 지상에서 기수가 들리지 않습니다. 이때 `PITCH`는 0°이지만 `ELEVATOR`에서 상승 입력을 확인할 수 있습니다. 70 KTS 이상에서 작은 양의 입력을 이륙 회전 의도로 판단해 목표 Pitch를 최소 +6°로 올립니다. 이륙 후 고도 100 FT까지는 상승 입력을 유지하는 동안 목표 Pitch를 최소 +6°로 유지합니다. 실제 `PITCH`가 부드럽게 +4°를 넘으면 이륙합니다. `INPUT —`는 오른손이 인식되지 않은 상태이며, 이지 모드에서는 손 위치가 자동 중립으로 설정됩니다. 핀치 때문에 검출이 잠깐 끊기는 경우는 750ms까지 조종 상태를 유지합니다.

## 오른손 중심 설정 (캘리브레이션)

중심 설정은 선택 사항입니다. 화면 어디서든 핀치하면 현재 손 위치와 거리를 조종 중립점으로 자동 사용합니다. `R` 커서 표시를 화면 중앙 조종간에 맞추고 싶을 때만 **C 키** 또는 **현재 자세로 설정 [C]**을 누릅니다. 오른손을 편한 위치에서 1.5초 유지하면 표시 중심 보정이 완료됩니다.

설정 후에는 그 손 위치에서 화면의 `R` 커서가 하단 조종간 중심에 놓입니다. 엄지·검지를 붙이면 잡히고, 이후 조종 방향은 기존과 같습니다. 미리보기 랜드마크는 실제 카메라 좌표 그대로 표시합니다.

설정된 손바닥 중심은 조종 입력의 고정 기준입니다. 손가락 끝 위치를 사용하지 않으므로 손가락을 벌렸다 핀치해도 기준점이 크게 변하지 않습니다. 핀치를 놓았다 다시 잡아도 새로 잡은 위치로 기준이 바뀌지 않으며, 설정 위치 근처에서는 핀치만으로 조종간을 다시 잡습니다.

- 손이 사라지거나 핀치하면 측정을 다시 시작합니다. 크게 움직여도 안정된 위치에서 재측정합니다.
- 20초 안에 측정이 끝나지 않으면 취소됩니다. 이전에 설정한 중심이 있다면 유지합니다.
- 측정 중 조종간은 놓이며 왼손 스로틀 입력과 비행 이동은 잠시 보류됩니다.
- **설정 취소**는 이전 중심을 유지합니다. **기본 위치로**는 원래 중심으로 복원합니다.
- 카메라 종료·장치 변경·좌우 손 교환 시 중심을 초기화합니다. 비행 초기화는 저장한 중심을 유지합니다.
- 새로고침하면 설정이 초기화됩니다. 손 이미지나 좌표를 디스크에 저장하지 않습니다.
- 카메라 화면 가장자리보다 손을 상하좌우로 움직일 여유가 있는 위치를 선택하세요.

설정 상수: `CALIBRATION_PREPARE_MS` (2000), `CALIBRATION_HOLD_MS` (1500), `CALIBRATION_TIMEOUT_MS` (20000), `CALIBRATION_STABILITY` (0.045).

## 조정 가능한 값

### 고급 모드: 카메라 거리로 앞뒤 조종

카메라를 사용자 정면에 두고 팔을 중간 정도 뻗은 편한 자세에서 C로 중심을 설정하세요. 손바닥 뼈대의 위치와 영상상 크기를 함께 저장합니다. 핀치한 손을 몸 쪽으로 당겨 카메라에서 멀어지면 기수가 올라가고, 카메라 쪽으로 밀면 기수가 내려갑니다. 좌우 이동은 Roll, 왼손 높이는 기존 스로틀 조작입니다. 카메라가 몸 뒤에 있으면 방향이 맞지 않습니다.

비행 화면의 `INPUT`과 아래 **PITCH 입력 확인**은 최종 Pitch 입력 미리보기입니다. `+`는 몸 쪽 당김에 의한 상승, `-`는 카메라 쪽 밀기에 의한 하강입니다. `상대거리`는 핀치하지 않아도 표시되는 원시 거리 변화이므로 먼저 이 숫자가 움직이는지 확인할 수 있습니다. 실제 비행 반영에는 `STICK: GRABBED`가 필요합니다.

기본값은 **이지 · 손 위치 조작**입니다. 고급 모드를 선택하면 핀치와 앞뒤 거리를 사용하며, 필요한 경우에만 **거리 모드 위아래 보조**를 켤 수 있습니다.

단안 웹캠의 손바닥 크기로 **상대 거리 변화**를 추정합니다. 표시되는 %는 최대 조종 입력 대비 비율이며 cm나 절대 거리 측정값이 아닙니다. MediaPipe의 z 좌표는 손목/손 중심을 기준으로 하기 때문에 카메라까지의 거리로 사용하지 않았습니다. [공식 좌표 설명](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)

- 손바닥을 기준 설정 때와 비슷한 방향으로 유지하세요. 회전·기울임·가림은 실제 거리 변화와 혼동될 수 있습니다.
- 손바닥 방향이 크게 달라지면 `손바닥 정면 권장`을 표시하지만 입력은 계속 유지합니다. 손 회전과 실제 거리 변화를 완전히 구분할 수는 없습니다.
- 핀치 전후 손 모양 변화의 영향을 줄이기 위해 손가락 끝 대신 손목과 손가락 뿌리를 사용합니다.
- 기준 근처의 작은 변화는 무시하고 거리 크기를 부드럽게 보간합니다. 앞뒤 이동에 따라 생기는 화면 좌표 변화도 완화합니다.

두 손의 역할은 이전 프레임 위치와 MediaPipe 좌우 판정을 함께 사용해 유지합니다. 한 손이 화면 밖으로 나가도 남은 손을 사라진 손의 역할로 자동 변경하지 않습니다. 처음부터 좌우가 반대로 표시될 때만 웹캠 아래의 `왼손 / 오른손 인식 교환`을 사용하세요.

## 비행 표현

상단의 **맵** 버튼을 누르면 비행 중에도 배경을 바꿀 수 있습니다. 선택은 브라우저에 저장되어 다음 접속에도 유지됩니다.

- **산악 도시**: 두 겹 산맥, 도심 건물, 창문과 간선도로
- **바다와 섬**: 푸른 수면, 반복되는 군도, 물결과 공항 섬
- **사막 기지**: 황갈색 산맥, 낮은 격납고형 건물과 기지 도로
- **야간 도시**: 별이 보이는 밤하늘, 어두운 빌딩, 밝은 창문과 도로등

상단의 **날씨** 버튼에서는 맑음, 석양, 흐림, 비, 안개를 선택할 수 있습니다. 날씨도 브라우저에 저장됩니다. 석양은 낮은 태양과 따뜻한 산란광, 흐림은 낮고 짙은 구름층, 비는 빗줄기와 조종석 유리 물방울, 안개는 움직이는 안개 띠와 짧은 시정을 적용합니다. 흐림과 비에는 약한 돌풍이 적용되며 손 조종을 방해하지 않는 범위에서 방위와 Roll이 조금 흔들립니다.

하늘, 지면, 구름, 산맥, 도시, 도로, 지면 격자와 자세 눈금이 같은 좌표계에서 움직입니다. 먼 산과 가까운 산은 서로 다른 속도로 흘러 깊이감을 만들고, 활주로 양옆에는 절차적으로 생성된 도시 건물과 창문 불빛, 간선도로가 이어집니다. 건물은 먼 곳부터 원근 투영하며 활주로 중앙 주변 160m는 비워 이착륙 시야를 유지합니다. 자유 비행에서도 속도와 방위에 따라 실제 지형 좌표가 이동합니다.

오른쪽 Roll이면 수평선은 반시계 방향으로 기울고, Pitch Up이면 수평선은 아래로 내려갑니다. 중앙 자세 기준선과 하단 조종석은 고정됩니다. 스로틀이 높으면 목표 속도가 증가하고, 속도와 Pitch를 이용해 고도를 갱신합니다.

70 KTS부터 화면 중심에서 바깥쪽으로 공기 흐름 선이 나타나며 속도가 높을수록 길고 선명해집니다. 지면 격자도 속도에 맞춰 조종석 방향으로 흐릅니다. 고속 비행과 활주 중에는 조종석에 작은 진동이 생기고, 58 KTS 미만의 공중 비행에서는 더 강한 버핏과 `STALL` 경고음이 발생합니다. 68 KTS를 넘으면 경고가 해제됩니다. 기수를 낮추고 스로틀을 올리면 회복할 수 있습니다.

실제 항공 물리, 정교한 실속, 전투는 구현하지 않았습니다. 자유 비행은 0%에서도 단순화한 활공 속도를 유지하고 고도는 0 FT 아래로 내려가지 않습니다. 훈련 모드에는 지상 가속·제동·저속 시 추가 하강·접지 및 활주로 이탈 판정을 적용합니다. 카메라 연결 전에도 자유 비행 배경은 동작합니다.

손 추적은 브라우저에서 처리하며 앱은 영상을 서버로 전송하거나 녹화하지 않습니다. MediaPipe JS, WASM, 모델을 내려받는 데 인터넷을 사용하므로 완전한 오프라인 앱은 아닙니다. 브라우저 다운로드 캐시는 환경에 따라 달라집니다.

### 웹캠이 켜지지 않는 경우

**영상에 카메라 꺼짐 그림이 나오지만 Windows 카메라 앱은 정상인 경우:** 미리보기 아래 **카메라 장치**에서 실제 웹캠을 선택하세요. 선택한 장치가 연결 중이라면 자동으로 전환합니다. 현재 입력 장치 이름도 목록 아래에 표시합니다. 가상 카메라 등이 기본 입력으로 선택된 경우를 해결하기 위한 기능입니다. Windows 카메라 앱은 확인 후 닫아주세요.

수정된 파일을 저장한 뒤 Live Server 페이지에서 `Ctrl+Shift+R`로 새로고침하세요. **웹캠 연결**을 누르면 버튼이 **권한 확인 중… → 손 추적 준비 중… → 웹캠 끄기**로 바뀝니다.

- 권한 확인 중: 브라우저의 카메라 허용 창을 확인합니다.
- 손 추적 준비 중: 카메라 영상은 켜져 있고 모델을 다운로드/초기화하는 단계입니다.
- 모델 초기화 실패: 이제 카메라를 자동으로 끄지 않고 영상과 오류 원문을 표시합니다. 연결 문제를 해결한 뒤 웹캠을 껐다 다시 켭니다.
- 오른손을 보여달라는 안내: 손 인식이 준비됐습니다. 인식되면 `R` 표시가 생깁니다. 이 표시는 마우스 커서가 아닙니다.

파일을 직접 열어도 시작 안내가 실행되도록 로컬 JS를 일반 `defer` 스크립트로 읽습니다. 실제 실행은 계속 Live Server를 사용하세요. WASM 및 GPU/CPU 초기화에도 시간 제한을 적용했습니다.

## MediaPipe 참고

[Google 공식 Hand Landmarker 웹 가이드](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)를 참고해 `FilesetResolver`, `HandLandmarker.createFromOptions`, `detectForVideo`, `handedness`를 사용했습니다. JS/WASM은 서로 같은 고정 버전 `0.10.22-rc.20250304`, 모델은 float16 버전 1을 사용합니다.

MediaPipe 추론은 동기식이어서 메인 스레드를 잠시 사용합니다. 이 버전은 세 파일 구조를 유지하면서 추론을 최대 24fps로 제한하고 Canvas는 `requestAnimationFrame`으로 갱신합니다. 저사양 기기에서 프레임 저하가 생길 수 있습니다.
